# 上游参考源码

来源：[lnys/starTower](https://github.com/lnys/starTower)，固定提交 [e41439a3d7a72f6053b2e86f0019543bda65ca27](https://github.com/lnys/starTower/tree/e41439a3d7a72f6053b2e86f0019543bda65ca27)。

此目录是用于地图/数据导出和行为对照的源码子集，包含原引擎、规则、组件、测试和设计文档，不是完整的可独立构建网页项目。原 `package.json` 为来源快照的一部分；请到上游仓库获取完整网页工程。

这些文件不参与 Flutter 应用运行。上游的 Node 测试可在仓库根目录运行 `npm test --prefix reference`，无需安装 Vue 依赖。许可证见 [LICENSE](../LICENSE)。
