## 1.0.1 真机闪退修复

- 设备：24129PN74C，Android 16。
- 原 1.0.0 历史记录有 4 次相同崩溃；新增真机回归在约 8 秒内重现相同 Java 崩溃。
- 原因链：MediaPlayer 播放完成 → audioplayers STOP 重置路径 → `prepareAsync()` 的 IllegalStateException。单改 RELEASE 后仍出现 `MEDIA_ERROR_UNKNOWN extra=-19`，未作为最终修复。
- 最终 Android 使用 audioplayers 的低延迟 SoundPool，使用现有 WAV 的数据长度/字节率计算复用时间；未更换素材或修改游戏规则。
- 修复后 debug 真机回归 38 秒通过，覆盖标题音乐、60 次重复点击音效、60 次移动、首场战斗（生命 988、金币 1）、撤销（生命恢复 1000）、10 次音乐楼层切换，以及框架注入的暂停/恢复生命周期事件。
- AOT profile 真机回归也在 36 秒内通过。最终 release 1.0.1（versionCode 2）已安装到手机，确认正常 MainActivity 在前台运行，测试包已移除。测试结束页已改为“测试完成，请打开正式版「星穹塔」”，避免空白测试页面被误认为游戏黑屏。
- 各 Android 短音符设为不单独请求音频焦点，防止音符互相打断；这一配置在最终安装包中。
- 后续 debug/profile 使用独立 `.debug` 包名。最初一次测试使用了正式包名，Flutter 测试框架结束时卸载该包，可能清除了旧存档；这是测试部署的问题，已记录并隔离。

## 1.1.1 音量调整

- 按最终试听反馈，在背景音乐 ×7、音效峰值平衡的基础上再增加 10 dB 预增益。使用 FFmpeg 前瞻限幅（5 ms 预看、20 ms 释放，补偿延迟），并为音乐与音效叠加保留余量；这是提高平均响度，峰值受限幅保护。
- 原旋律、音序、文件时长与用户音量/静音设置保留；此版获授权改变音频动态和相对响度，不再声称音频振幅与上游逐样本一致。
- 全部 419 个文件无样本削波；51 组音乐按原间隔叠加两轮后，最高音乐峰值约 0.50，最大单音效峰值 0.48，保守合计 0.98。多个音效同时密集叠加的最终系统混音不在此边界内。
- `tool/master_audio.mjs` 实现离线母带处理并断言时长与限幅上限；原导出脚本同步调用。日常运行和构建不需要 FFmpeg。
- 18 项 Flutter 回归、静态分析及音频/数据资源校验通过。17 dB 档的真机测试因调试服务连接中断未完成，测试进程仍存活且未记录该进程崩溃；不能将该轮记为通过。

- 最终 1.1.1（versionCode 4）已覆盖安装并启动正式 MainActivity；更新前后首次安装时间及 CE/DE 数据目录 inode 相同，独立测试包已移除。最终限幅音频已验证打入 APK；这一档尚未完成全程真机自动化回归，实际响度需用户试听确认。

## 1.1.2 音量再次提高

- 在上一档离线预增益基础上额外增加 20 dB（预增益系数 ×10）；取消 `balanceMusic` 整体降幅，峰值保护上限从 0.45/0.48 提高为 0.98，预看 1 ms、释放 5 ms。
